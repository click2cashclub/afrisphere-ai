# AfriSphere AI — Brand Reference

## Color palette

Defined in `website/app/globals.css`, used consistently across the entire
site and product (marketing pages and the Zuri chat product both draw
from this same palette as of August 2026).

| Name | Hex | Use |
|---|---|---|
| `forest` | `#14532D` | Primary — dark green, dominant background/brand color |
| `sunrise` | `#EA580C` | CTA / action color — all primary buttons |
| `heritage` | `#CA8A04` | Accent — highlights, badges, secondary emphasis |
| `deepblue` | `#1E3A8A` | Secondary — used in gradients (e.g. Hero, Waitlist) |
| `warmwhite` | `#FAFAF9` | Light background |

Hover convention: `bg-sunrise` buttons use `hover:bg-orange-600`.

## Typography

- **Headings:** `font-serif` (DM Serif Display) — applied to every section
  heading across the live site.
- **Body:** `font-sans` (Inter) — default body text.

## Button convention

All primary CTA buttons use `rounded-full` (pill shape) with
`bg-sunrise` and `text-white`. This was standardized in August 2026 after
an audit found one button (`HeroSearch`) using `rounded-2xl` instead —
keep new buttons consistent with the pill shape.
